*DESCRIPTION* : In this project, I developed a Chrome Extension titled “Time Tracking and Productivity Analytics”, designed to monitor user activity across different websites, analyze time spent, and visualize productivity trends with the help of a dynamic dashboard. The core objective of this extension is to classify websites as productive (like github.com, w3schools.com) or unproductive (like youtube.com, bing.com, etc.) and track the duration spent on each throughout the day or week. The data is stored locally using JSON files and can also be sent to a Node.js backend (via server.js) for further processing, making this extension scalable for user-specific logging in future iterations. I used Visual Studio Code (VS Code) as the primary code editor to develop this extension, leveraging HTML, CSS, JavaScript, and Node.js along with supporting Chrome Extension files such as manifest.json to register the extension and define permissions, background behavior, and content scripts. The popup.html provides users with quick access to the "Open Dashboard" feature, allowing them to monitor their activity in real-time. One of the challenges I overcame was filtering out irrelevant domains like localhost and newtab that don't represent meaningful usage data. These anomalies were cleaned through domain validation in JavaScript before logging. For chart visualization, I used Chart.js, which renders a clean, responsive doughnut chart showcasing website usage distribution. The layout and UI/UX were made appealing with custom CSS styling ensuring that the dashboard looks neat, responsive, and easy to understand. This extension runs in the browser background and tracks active tabs using the chrome.tabs and chrome.runtime APIs, recording the domain name and time spent in each session. Such a tool has wide applicability in today's productivity-driven digital workspace—whether for students, remote workers, or freelancers—as it offers clear insight into how online time is spent and where productivity leaks occur. Employers or individuals can use it to enforce digital discipline, allocate time more efficiently, and ultimately build better digital habits. The backend server using Node.js can be extended to store user-specific data in a database (e.g., MongoDB) for multi-user support. Each JSON entry in localStorage or server memory contains domain-specific durations, updated periodically as the user switches tabs. The extension is also compatible with all Chromium-based browsers and can be installed directly from the Developer Mode in Chrome Extensions settings. The project is modular and cleanly structured, allowing scalability for features like daily/weekly summary reports, email alerts for excessive unproductive browsing, or leaderboard comparisons in team environments. As shown in the screenshot, the output is a “Weekly Productivity Report” containing a doughnut chart that breaks down time spent across platforms like GitHub, YouTube, W3Schools, Bing, and others. The legend clearly shows categorized websites with distinct colors, providing an at-a-glance understanding of where the user’s digital attention went. The entire extension code is deployed and tested using Live Server for local HTML rendering during development, and VS Code terminals were used to run server.js and simulate backend interaction. Overall, this project integrates front-end development, backend logic, Chrome API usage, and data visualization, making it an excellent example of a hybrid full-stack mini tool aimed at digital wellness and time management.
